# WEEK 7 – Generative AI Programming Practical

## Aim
Inspect next-token probabilities by examining logits and top-K candidates from a small open-source language model using Hugging Face Transformers.

## Files
- `main.py` – loads GPT-2, tokenizes four prompts, calculates next-token probabilities, displays the top five candidates and saves the results.
- `requirements.txt` – required Python packages.
- `.gitignore` – excludes virtual environments and Python cache files.

## Run in VS Code (Windows PowerShell)

Open the `WEEK7` folder in VS Code and open a terminal in that folder.

### 1. Activate your existing GenAI virtual environment
If `.venv` is in the parent `GenAI` folder, run this from inside `GenAI\LAB\Week7`:

```powershell
..\..\.venv\Scripts\Activate.ps1
```

If the Week7 folder is opened independently and you want a separate environment instead:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. Install requirements

```powershell
python -m pip install -r requirements.txt
```

### 3. Run the program

```powershell
python main.py
```

The first run downloads the GPT-2 model from Hugging Face, so an internet connection is required. Keep the terminal open while the model loads and the program runs.

## Expected output
For each of the four prompts, the program displays:
- Input token IDs
- The five most likely next-token candidates
- Each candidate's token ID and probability

It also creates `week7_probability_results.csv` in the current Week7 folder. The CSV contains the prompt, rank, candidate token, token ID and probability.

## Notes
The model is `openai-community/gpt2`, as specified in the practical. The results are generated by the model at runtime and may vary with library/model versions.
